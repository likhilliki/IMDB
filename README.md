# 🎬 IMDB Movie Ratings Analysis

This project performs exploratory data analysis on real IMDB movie ratings data to identify trends in movie ratings and genres. The analysis includes data cleaning, statistical summaries, visualizations, and a simple dashboard to present insights.

---

## 📌 Objectives
- Clean and preprocess IMDB movie rating data
- Calculate summary statistics (mean, median, mode)
- Visualize rating distributions using histograms and box plots
- Identify top-rated movies and genres
- Build a simple analytical dashboard

---

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

---

## 📂 Dataset
- Source: IMDB dataset from Kaggle  
- Contains movie titles, genres, release years, and IMDB ratings

---

## 📊 Key Features
- Data cleaning and preprocessing
- Statistical analysis of IMDB ratings
- Genre-wise rating analysis
- Visual insights through plots
- Simple dashboard for summary visualization
